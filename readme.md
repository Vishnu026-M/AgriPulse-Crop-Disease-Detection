# AgriPulse – AI-Powered Crop Disease Detection

AgriPulse is an AI-powered web application that detects crop diseases using Convolutional Neural Networks (CNN).

## Features
- Crop Disease Detection
- Image Upload
- Prediction History
- FastAPI Backend
- React Frontend

## Technologies
- React.js
- FastAPI
- TensorFlow
- Python
- SQLite

## Run Project

Backend:
uvicorn main:app --reload

Frontend:
npm install
npm run dev
